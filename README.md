# Library Management System

A simple Python project to manage books and members.

## Features
- Add books and members
- Issue and return books
- Display available and issued books

## Project Structure
- `main.py`: entry point
- `book.py`: Book class
- `member.py`: Member class
- `library.py`: library operations
- `data/books.txt`: book data

## How to Run
Run `main.py` in PyCharm, or use `python main.py` in the terminal.
